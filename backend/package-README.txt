============================================================
📦 package.json 里每个字段的意思
============================================================

【name】        项目名字，随便取，不影响功能
【version】     版本号，自己管理
【description】 项目描述，给自己和别人看的

【main】        程序入口文件，npm start 会运行这个文件

【scripts】     命令快捷方式
                - start: 运行 node server.js（其实不写也行，npm默认会找server.js）

【dependencies】依赖的第三方库（三个都是npm下载量前几名的明星库）

  📦 express
     作用：Node.js最流行的Web框架，用来写HTTP接口（API）
     比如：app.get('/api/scores', ...) 就是用它写的

  📦 better-sqlite3
     作用：操作SQLite数据库的库
     特点：
       - SQLite 是"文件数据库"，整个数据库就是一个 .db 文件，不用装MySQL那种服务器
       - better-sqlite3 是同步API，写起来简单，性能比sqlite3好很多
       - 适合中小项目，排行榜这种完全够用

  📦 cors
     作用：跨域资源共享中间件
     为什么需要？如果前端和后端不在同一个域名/端口，浏览器会阻止请求（跨域限制）
     Docker里我们用Nginx反代后是同源的，但如果你把前端部署Netlify、后端部署别的地方，就必须用它

============================================================
关于版本号的 ^ 符号：
  "express": "^4.19.2"
  ^ 的意思是：允许安装 4.x.x 的最新版本，但不允许升级到 5.0.0（大版本可能不兼容）
